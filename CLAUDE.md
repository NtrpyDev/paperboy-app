# Paperboy

Paperboy is a free, open source Android app: an endless feed of new science and math papers, each one explained visually.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues on `NtrpyDev/paperboy-app`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage labels, each named after its role. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

## Writing rules

- No em dashes anywhere: code, comments, copy, commits, docs.
- American English.
- Plain, specific wording. No filler phrases.
